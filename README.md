# domino-academic_domino_effect
judul aplikasi : Domifect

Deskripsi : Website simulator akademik untuk mengingat jadwal pelajaran, tugas atau PR, dan leaderboard untuk siswa SMA/SMK  

Latar belakang: **DOMIFECT** (*Domino Effect Academic & Vocational Planner*) dilatarbelakangi oleh tingginya tingkat penundaan waktu (*procrastination*) di kalangan siswa SMA dan SMK, yang sering kali berujung pada krisis akademik dan stres psikologis menjelang *deadline*. Sebagian besar aplikasi *planner* konvensional hanya mencatat daftar tugas secara kaku tanpa memperhitungkan hubungan sebab-akibat. Padahal, pada dunia pendidikan modern dan kejuruan—seperti laporan praktik bengkel atau proyek PKL—keterlambatan pada satu tugas awal akan memicu efek domino yang merusak seluruh jadwal tugas berikutnya.

Untuk mengatasi hal tersebut, aplikasi ini dirancang dengan **Mesin Bank Kalimat Teror Guru (500+ variasi kombinasi dinamis)** yang mencakup berbagai karakter pengampu, mulai dari gaya *Killer*, *Sarkas*, *Disiplin*, hingga instruktur kejuruan. Sistem ini memberikan teguran psikologis yang lebih hidup dan personal secara berkala melalui notifikasi *heads-up* di luar aplikasi, sehingga mampu memicu kedisiplinan siswa secara efektif tanpa terkesan monoton.

Selain itu, **DOMIFECT** dikembangkan sebagai aplikasi mandiri (*True Standalone WebAPK*) murni yang dapat di-download langsung dari Google Chrome di HP, lengkap dengan antarmuka khusus layar ponsel (*Mobile-First*) dan kemampuan bekerja secara *offline*. Dilengkapi pula dengan fitur pendukung seperti **Panic Button**, kalkulator beban mental, dan simulator efek domino, aplikasi ini hadir sebagai solusi total bagi siswa untuk mengembalikan kendali penuh atas manajemen waktu dan produktivitas mereka.

teknologi yang digunakan : HTML, CSS, JavaScript

pemanfaatan AI : Gemini

Panduan penggunaan : - siswa menambahkan jadwal tugas baru 
                     - siswa melihat leaderboard pengerjaan PR
                     - siswa melihat notifikasi dari guru 
                     - siswa dapat notifikasi pengingat tugas
