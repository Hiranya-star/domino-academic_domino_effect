📲 Cara Download / Install DOMINO di HP

Aplikasi ini menggunakan teknologi Progressive Web App (PWA) sehingga bisa dipasang di HP tanpa Play Store:

  1. Android (Chrome): Ketuk ikon titik tiga (⋮) di pojok kanan atas ➔ pilih "Tambahkan ke Layar Utama" / "Install App".
  2. iPhone / iPad (Safari): Ketuk ikon Bagikan (Share) ➔ pilih "Add to Home Screen".
  3. Laptop / PC: Klik ikon Install di bilah alamat URL kanan atas.
